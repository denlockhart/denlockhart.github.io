# Plus Practice

Kids addition flash-card game for denlockhart.com.

## Rules

- Choose lesson length: **10, 20, or 30** cards
- One addend is always from your **selection**; the other is a **random 1–10**
- Tap numbers or use groups (All / 1–5 / 6–10) to set the selection
- Selection and lesson size are saved in `localStorage`
- Each card is logged by the **first** answer (right or wrong) for lesson review
- **Review missed** re-practices cards that were wrong on the first try
- **Clear lesson** starts a fresh lesson of the chosen length
- Four answer choices per card; keep trying until correct
- Optional apples beside each addend
- Tracks streak plus first-right / first-wrong counts
