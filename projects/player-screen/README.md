# Player Screen

A two-window picture board for a Windows PC with a second monitor. Choose a folder of images on this machine. Click one. That picture replaces whatever is on the player window.

This is the same Windows PC, not a game server and not a second computer. Open the page in Brave, Microsoft Edge, or Chrome.

## Use it

1. Open http://localhost:3000/projects/player-screen/ or https://www.denlockhart.com/projects/player-screen/
2. Choose a folder, or drop the folder on the page.
3. Click **Open player screen**. The new window opens to the right of this one.
4. Drag that window onto the other monitor and press **Full screen**.
5. Click an image on the first window. The other screen replaces the previous picture.

Arrow keys move to the next or previous image. **Blank** clears the player screen. **Whole image** shows the entire picture. **Fill screen** crops it to cover the monitor.

Images stay in the browser for this visit. Nothing is uploaded.
